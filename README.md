# Payment API

API REST em Java 21 + Spring Boot que simula o processamento de pagamentos de pedidos, com foco em idempotência, máquina de estados, transações e segurança.

> Projeto em desenvolvimento, construído fase a fase como estudo guiado de backend Java. Este README será completado na fase final do projeto (documentação completa de endpoints, autenticação, idempotência, webhooks, testes, Docker, decisões técnicas e diagrama de arquitetura).

## Stack

- Java 21
- Spring Boot 4 (Web MVC, Data JPA, Security, Validation)
- PostgreSQL + Flyway
- JWT
- Docker / Docker Compose
- JUnit 5, Mockito, Testcontainers
- Swagger / OpenAPI
